# Note style

- **Long notes start with a "Start here" block** (owner's request 2026-11-27): a `[!todo]` callout of actions grouped by
  when (now, every year, later) with `[[#Heading]]` links, then a numbered "jump to" table (section, what's in it).
- **Each section opens with one bold "In short:" line**, then the detail. Group by topic, not by when it was researched.
